# Avaliação 3 - Flexbox e Layout

**Objetivo:** Estruturar a página aplicando conceitos de CSS Flexbox no arquivo `style.css`.

## Requisitos do Layout

1. **Estrutura Principal:** O corpo da página (`body`) deve preencher no mínimo 100% da tela (`100vh`). Organize suas seções (Header, Main, Footer) em uma única coluna vertical, garantindo que a área central se expanda para preencher o espaço livre.
2. **Distribuição:** 
   - No Cabeçalho: separe os elementos nas extremidades opostas.
   - No Rodapé: centralize os elementos e permita a quebra de linha automática (`wrap`) caso falte espaço.
3. **Proporções:** Na área central, a barra do meio deve ser **duas vezes mais larga** que as barras laterais (utilize a propriedade `flex`).
4. **Alinhamento Interno:** Todo texto dentro das "caixas" coloridas da interface deve estar perfeitamente **centralizado** (horizontal e verticalmente) usando Flexbox.
5. **Boas Práticas:** Evite repetição agrupando seletores CSS semelhantes. Todas as caixas visíveis devem possuir o mesmo efeito de elevação suave no `hover`.

**Critérios de Avaliação:** Correta aplicação do `display: flex`, domínio das propriedades de alinhamento/distribuição, dimensionamento proporcional e código enxuto.
